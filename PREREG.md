# CBIO045 "Viral Genome Annotation with RNNs" - preregistration (before any model scored)
Data: NCBI RefSeq viral release, first 60,000,001 bytes of viral.1.genomic.gbff.gz (3,123 complete records, 77 Mb; URL https://ftp.ncbi.nlm.nih.gov/refseq/release/viral/viral.1.genomic.gbff.gz, byte range 0-60000000, hash in data_manifest). The file is ordered by accession, so this is NOT a random sample of viral diversity (Orthornavirae-heavy). Gene annotations are RefSeq's own (computational and curated mixed), so labels are not independent ground truth.
Task: per-base labelling of coding sequence on either strand (1 = inside any annotated CDS), from DNA only, windows of 900 nt stride 450.
Selection: records 1,000-20,000 nt with >=1 CDS. Split by taxonomy: held-out families = every record whose lineage field [4] (or [3] if missing) is in a held-out set; ~25% of lineage groups held out (seed 0) -> cold-lineage test; also a random-record split for contrast. Train up to 400 records, test up to 200 (fixed seed).
Models: (B1) ORF caller: stop-to-stop ORFs on 6 frames >= L nt marked coding, L in {150,300,450,600,900} picked by best F1 on TRAIN records. (B2) logistic regression on per-window k-mer (k=3) frequency + GC, labelled by window majority, painted to bases. (M) small neural net: embedding(4->16) -> Conv1d(k=9,64) -> BiGRU(64) -> linear, 3 epochs, Adam 1e-3, seed 0, CPU.
Metrics (held-out bases): F1, MCC, AUROC (M and B2). Gates: D2 M cold-lineage F1 >= best baseline F1 + 0.02; D3 gap random vs cold F1 <= 0.05 (generalises across lineages).
Directions: D1 data stats; D2 cold-lineage comparison; D3 random-split contrast; D4 per-lineage-group F1 spread (worst/best); D5 effect of GC content bins; D6 window-size ablation not run (stated; SUPERSEDED: later run as an extension, see PREREG_EXT.md and RESULTS.md); D7 ORF length threshold sensitivity; D8 error profile: boundary vs interior errors (fraction of errors within 30 nt of CDS edges); D9 overlap-gene stress (records with overlapping CDS: F1 vs without); D10 length effect: F1 vs genome length bins.
Limits: labels come from RefSeq annotations (themselves partly predicted by ORF/homology tools, so ORF baselines are favoured); no comparison to Prodigal/GeneMark (not installed here); CPU, one seed, small training set.
